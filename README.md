# LearnHub LMS (React)

A learning management system built with React 18, React Router and Vite.

## Features
- Student dashboard, course catalogue (search, category filter, sorting), course details
- Enrolment, My Courses, lesson viewer with previous/next navigation
- Quiz with score calculation and answer review
- Student profile and admin course management
- Progress persisted in localStorage; responsive, dark-mode aware UI

## Run
```bash
npm install
npm run dev
```

## Structure
`src/context` global state, `src/hooks` reusable hooks, `src/components` reusable UI, `src/pages` route screens, `src/data` seed data.
